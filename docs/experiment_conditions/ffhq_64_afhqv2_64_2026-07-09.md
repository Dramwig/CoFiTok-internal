## Preprocessing

FFHQ-64:

- The raw ZIP already contains 64x64 PNG files.
- Extraction only; no crop, resize, normalization, filtering, or generated split was applied.

AFHQv2-64:

- The raw parquet files contain 512x512 images.
- Images were converted to RGB and resized to 64x64 with PIL LANCZOS.
- Output was written under class-name directories for traceability.
- Class labels may be used by experiments for optional class-conditional controls, but `S_k` must not receive labels, timestep, prompt, previous tokens, or other conditioning.

## Experiment Use

Recommended placement in the paper plan:

- `ffhq_64`: P0 non-classification face dataset; use for prefix visualization and global-to-local denoising interpretation.
- `afhqv2_64`: P0/P1 non-classification animal dataset; use for late-token texture/detail utilization diagnostics.
- `downsampled_imagenet_64`: remains the strict 64x64 main table source.
