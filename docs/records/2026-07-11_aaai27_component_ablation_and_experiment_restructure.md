Paired interpretation:

- Full versus endpoint-only: path AUC `-93.0%`; endpoint MSE `+2.0%`.
- Full versus no path-prefix: path AUC `-45.7%`; endpoint MSE `+0.04%`.
- Full versus no path-component: path AUC `-37.9%`; endpoint MSE `-0.14%`.
- Full versus simultaneous: mean path AUC `-2.8%` and endpoint MSE `-1.0%`,
  but path wins only one of two seeds. Sequential feedback is therefore an
  optional default implementation, not part of the core claim.
- Deep synthesis can improve path AUC but fails the defining zero-token
  contract. Restricted synthesis is justified by identifiability rather than
  by selecting the lowest scalar reconstruction metric.
- Parameter-matched direct dense is 0.6% lower in endpoint MSE in this 64px
  two-seed protocol but has no native multi-prefix interface. The independent
  ImageNet-256 confirmatory protocol gives CoFiTok a 6.73% endpoint advantage.

## Hyperparameters

- Increasing either path-loss weight steadily lowers path AUC while endpoint
  MSE moves little; `(0.15, 0.30)` is a moderate endpoint/path tradeoff.
- Progress power 1.5 is the clear minimum when all models are judged against the
  same power-1.5 path.
- K8 has the lowest mean path AUC; K4 has slightly lower endpoint MSE; K16 adds
  short-budget cost without a path gain.
